
# Marketing Analytics Dashboard (Excel)

## 📌 Project Overview

This project presents an interactive Excel dashboard designed to analyze marketing campaign performance and track key marketing KPIs.

## 🎯 Objectives

* Monitor campaign performance
* Track impressions and conversions
* Analyze marketing KPIs
* Support data-driven decision-making

## 🛠 Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts


## 📊 Key Metrics

* Impressions
* Clicks
* Conversion Rate
* Campaign Performance
* Marketing KPIs

## 💡 Insights

The dashboard helps identify top-performing campaigns, monitor marketing effectiveness, and evaluate overall campaign performance through interactive visualizations.
